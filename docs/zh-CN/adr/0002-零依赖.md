# ADR 0002 — 零第三方依赖

**状态：** 已接受
**适用范围：** 整个工作区

## 背景

游戏引擎是最有可能比它的依赖活得更久的软件。Rust 生态的 crate 都很优秀，但每一个都带来一个版本范围、一份编译期开销、一个许可证、一块审计面，以及一份不再维护的传递依赖的风险。一个 vendor 了三十个 crate 的引擎，就是任何一个 crate 发布破坏性变更都会构建失败的引擎。

还有一个工作流上的理由。本项目主要由 AI agent 编写，而一个能读懂自己依赖的每一行的 agent，才能端到端地推理行为。面对陌生 crate 未文档化的边界情况，agent 做不到。

## 决策

**不引入任何第三方运行时依赖。** 工作区只依赖 `std`。连 PNG 编解码器都是从零写的：`noxel-asset::png` 包含一个完整的 DEFLATE 解压器（stored、fixed-Huffman 与 dynamic-Huffman 块）和一个 fixed-Huffman 压缩器，外加 CRC-32 与 Adler-32。

每个 crate 都声明：

```rust
#![forbid(unsafe_code)]
#![deny(missing_docs)]
#![warn(clippy::all)]
```

## 换来什么

- `cargo build` 在无网络的全新机器上可用。
- 整个工作区几秒内构建完成，因此 AI agent 可以快速迭代。
- 任何地方都没有 `unsafe`：每个切片索引都经过检查，每个 `as` 转换都经过考量，借用检查器是唯一需要的 UB 防线。
- PNG 编解码器对照一个独立实现做了验证：测试套件交叉检查往返，开发期间还验证了我们的压缩器输出能被 CPython 的 `zlib` 逐字节精确解压。

## 代价是什么

一次性的、在树内完成的实打实的工作：

| 通常用哪个 crate | 这里 |
|---|---|
| `png` / `image` | `noxel-asset::png`、`noxel-asset::image`（1996 + 883 行） |
| `serde_json` | `noxel-asset::json`，一个保持插入顺序、带行/列错误的解析器 |
| `glam` | `noxel-core::math` |
| `rand` / `fastrand` | `noxel-core::rng`（PCG32 + 可寻址流） |
| `rayon` | `noxel-core::jobs`，基于 `std::thread` 的作用域作业池 |
| `winit` / `SDL2` | **没有替代**——见下文 |
| `noise` | `noxel-core::math::noise`，基于哈希，因此任意坐标都可采样 |

## 例外：窗口

窗口需要平台 API，重新实现 `winit` 超出范围。因此 Noxel **没有窗口层**。`App` 产出 `Framebuffer` 并消费 `InputState`；呈现缓冲区是宿主的职责。`docs/guides/windowing.md` 展示了如何在可选 feature flag 背后接上 `winit` 或 `SDL2`，而 `town-demo` 示例写出 PNG 帧，因此引擎在完全没有显示服务器的情况下也完全可用——并且完全可测。

## 唯一的例外

`noxel-window`（见 [ADR 0011](0011-窗口.md)）依赖 `winit` 与 `softbuffer`，因为仅靠 `std` 打不开窗口。这个依赖是**可选的、默认关闭的，且只存在于那一个 crate 里**：`cargo build --workspace` 与 `cargo test --workspace` 既不编译它，也依然什么都不下载。其他一切地方的规则不变，想在别处加依赖就需要再写一份 ADR。

## 后果

- GPU 后端（见 ADR 0007）是唯一一个真正难以避免依赖的地方；它被规定为 **feature-gated**，因此默认构建保持零依赖。
- 短期内开发更慢：写一个 DEFLATE 编码器不是免费的。
- `#![forbid(unsafe_code)]` 这条线也有真实代价——`PaletteFile::to_palette` 不得不 `Box::leak` 条目名字符串，因为 `Palette::push` 需要 `&'static str`，而不使用 unsafe 就无法从自有数据构造一个。该泄漏的上界是调色板条目数量，并在原处有文档说明。

## 被否决的替代方案

- **使用生态、用 `cargo vendor` 打包**：解决了可复现性，没解决可审计性，而且构建仍然依赖那些 crate 能编译。
- **允许一份小的白名单（`glam`、`png`）**：白名单会增长；没有自然的停止点。
