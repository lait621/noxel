# API 索引

`cargo doc` 是下列每一项的参考。本页是一张地图：哪个 crate 做什么、先导入什么、接下来去哪里看。

```bash
export PATH="$HOME/.cargo/bin:$PATH"
cargo doc --workspace --no-deps --open     # writes target/doc/ and opens it
```

生成的页面也可以从本文件直接访问：
[`target/doc/noxel_core/index.html`](../../../target/doc/noxel_core/index.html)。
把 `noxel_core` 换成表格中的任意 crate 名即可。

## crate

| crate | 用途 | 预导入 | 你会最先接触的五个类型 |
|---|---|---|---|
| [`noxel-core`](../../../target/doc/noxel_core/index.html) | 数学、确定性 RNG、计时、作业池、槽映射、空间结构、事件总线。其他每个 crate 都依赖它，而它不依赖任何东西 | `noxel_core::prelude` | `Vec3`、`Mat4`、`Transform`、`RngStream`、`GameClock` |
| [`noxel-ecs`](../../../target/doc/noxel_ecs/index.html) | 带分阶段调度器的稀疏集实体/组件世界 | `noxel_ecs::prelude` | `World`、`Entity`、`Scheduler`、`Component`、`Resource` |
| [`noxel-asset`](../../../target/doc/noxel_asset/index.html) | JSON、从零写的 PNG 编解码器、图像、纹理、图集打包、数据格式（`TileSet`、`Prefab`、调色板、精灵）以及一个热重载数据库 | `noxel_asset::prelude` | `AssetDb`、`Image`、`Texture`、`TileSet`、`Prefab` |
| [`noxel-render`](../../../target/doc/noxel_render/index.html) | 一个场景、两个渲染器：图块分箱的软件光栅化器与 CPU 光线追踪器，外加混合模式；线性 HDR 帧缓冲，一次 sRGB 解析 | `noxel_render::prelude` | `Scene`、`Material`、`Mesh`、`Framebuffer`、`RenderSettings` |
| [`noxel-camera`](../../../target/doc/noxel_camera/index.html) | 俯视相机装配：焦点、死区、与帧率无关的平滑、前瞻、缩放、抖动、区域、像素完美吸附 | — | `TopDownCamera`、`ProjectionMode`、`PixelPerfect`、`CameraShake`、`CameraZone` |
| [`noxel-visibility`](../../../target/doc/noxel_visibility/index.html) | 三阶段剔除（视锥、距离/尺寸、遮挡）、相机遮挡淡化表与 LOD 选择 | — | `VisibilitySystem`、`VisibilityInput`、`CullSettings`、`OcclusionSettings`、`LodLevels` |
| [`noxel-physics`](../../../target/doc/noxel_physics/index.html) | 固定步长的确定性刚体、顺序冲量求解器、层、查询与运动学角色控制器 | — | `PhysicsWorld`、`BodyDesc`、`ColliderShape`、`BodyHandle`、`CharacterMove` |
| [`noxel-world`](../../../target/doc/noxel_world/index.html) | 程序化地形、生物群系、道路、城镇、杂物、区块数据与 LRU 流式加载，全部是 `(seed, position)` 的纯函数 | — | `WorldConfig`、`WorldGenerator`、`WorldStreamer`、`Chunk`、`BiomeId` |
| [`noxel-npc`](../../../target/doc/noxel_npc/index.html) | 人群层级、A\*/流场寻路、转向与日常日程，由 `WorldStreamer` 与 `PhysicsWorld` 之上的单个 `NpcSystem` 驱动 | — | `NpcSystem`、`NpcConfig`、`NpcContext`、`CrowdManager`、`NpcAgent` |
| [`noxel-debug`](../../../target/doc/noxel_debug/index.html) | 带百分位的滚动统计、区段预算、叠加层面板与帧转储/差异 | — | `DebugSystem`、`DebugConfig`、`Stats`、`FrameDumper`、`ImageDiff` |
| [`noxel-window`](../../../crates/noxel-window) | 把帧缓冲呈现到屏幕并读取玩家输入；唯一带可选第三方依赖的 crate |
| [`noxel-app`](../../../target/doc/noxel_app/index.html) | 运行时宿主：固定步长帧循环、共享上下文、插件注册表、无头运行器 | — | `App`、`AppConfig`、`AppContext`、`Plugin`、`InputState` |

`tools/noxel-gen` 是一个二进制而非库：用
`cargo run -p noxel-gen -- --help` 运行它。它写出引擎所加载的资源树
（tile set、prefab、调色板、精灵、地形）。

## 我想要哪个 crate？

| 任务 | 从这里开始 |
|---|---|
| 让角色带碰撞地移动 | `noxel_physics::PhysicsWorld::move_character`、`docs/06-physics.md` |
| 决定画什么 | `noxel_visibility::VisibilitySystem`、`docs/05-camera-and-visibility.md` |
| 让受光场景看起来正确 | `noxel_render::Material`、`Light`、`docs/04-rendering.md` |
| 生成或查询世界 | `noxel_world::WorldGenerator`、`WorldStreamer`、`docs/03-world-generation.md` |
| 把一个游戏接起来 | `noxel_app::App`、`Plugin`、`docs/01-architecture.md` |
| 查出一帧为什么慢 | `noxel_debug::DebugSystem`、`docs/08-performance.md` |
| 让一座城镇挤满人 | `noxel_npc::NpcSystem`、`docs/07-npcs.md` |
